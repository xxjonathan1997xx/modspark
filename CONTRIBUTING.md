# Contributing

Issues and pull requests are welcome. Keep changes focused, run `npm ci`, `npm test`, and `npm run build`, and describe any platform limits in the pull request.

ModSpark is a clean-room project. Do not submit WeMod code, assets, decompiled implementation details, or trainer files you do not have permission to redistribute.

Catalog entries must link to a source the publisher is authorized to distribute, declare a license and tested game builds, and include exact file sizes and SHA-256 hashes. Catalogs are signed by their maintainers; never commit private signing keys.
